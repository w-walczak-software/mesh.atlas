# Backend Rules

Use:
- Java 21
- Spring Boot 3
- Spring Data JPA
- Hibernate
- PostgreSQL
- Flyway
- MapStruct
- Maven

Frontend:
- Angular 19
- Angular Material

Architecture:
- Modular monolith initially
- Evolutionary architecture
- Domain-driven design
- Hexagonal architecture where appropriate
- Metadata-driven architecture
- Enterprise integration patterns

Never:
- expose entities directly
- use enums for business dictionaries
- user field injection
- use anemic services
